Battleship Radar – это консольная реализация классической игры «Морской бой» на 8 языках программирования. Проект создан как тестовый репозиторий для демонстрации решения одной задачи на разных языках с использованием идиоматичных подходов и продвинутых возможностей каждого языка.

Игра реализована в формате «человек против компьютера» на поле 10×10. Корабли расставляются случайно в начале игры. Игрок и компьютер по очереди делают выстрелы по координатам (например, A1). Программа отображает два поля: своё (с кораблями) и поле противника (с отметками попаданий и промахов). Игра заканчивается, когда все корабли одной стороны уничтожены.

Особенности реализации
Случайная расстановка кораблей (стандартный набор: 1 четырёхпалубный, 2 трёхпалубных, 3 двухпалубных, 4 однопалубных).

Ввод координат в формате БукваЦифра (например, B5).

Визуализация полей с символами:

~ – вода

# – корабль (виден только на своём поле)

X – попадание

O – промах

Компьютер стреляет случайным образом (без умной стратегии, но можно добавить).

Завершение игры при потоплении всех кораблей одной стороны.

Логирование ходов (опционально) – вывод истории выстрелов.

Продвинутые фичи (в различных реализациях)
Валидация ввода и обработка ошибок.

Подсветка ходов (цветной вывод в терминале) – где возможно.

Сохранение состояния игры в файл (опционально).

Режим «умного» компьютера (поиск соседних клеток после попадания) – реализован в некоторых версиях.

Модульные тесты (для языков с поддержкой).

Использование современных фич языка (record, pattern matching, async/await и т.д.).

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Установка	Запуск
Python	Python 3.8+	python battleship.py
JavaScript	Node.js 14+	node battleship.js
Go	Go 1.18+	go run battleship.go
Java	JDK 11+	javac Battleship.java && java Battleship
C#	.NET SDK 6.0+	dotnet run или csc
PHP	PHP 7.4+	php battleship.php
Ruby	Ruby 2.7+	ruby battleship.rb
TypeScript	Node.js + npm install -g ts-node typescript	ts-node battleship.ts
Правила игры
Игровое поле 10×10, строки обозначаются буквами A–J, столбцы – цифрами 1–10.

Корабли расставляются случайно в начале игры.

Игрок делает ход, вводя координату (например, A1).

Если выстрел попал в корабль, на поле ставится X, и игрок получает дополнительный ход (в классических правилах, но в нашей реализации ход переходит к компьютеру – для простоты).

Если промах – ставится O, ход переходит к компьютеру.

Компьютер стреляет случайно.

Игра продолжается, пока все корабли одного игрока не будут уничтожены.

В конце выводится победитель.
